# 阅读板（Reading board）

把一段回复钉在右侧栏里慢慢看，再就其中看不懂的地方回到主聊天提问。

## 用起来是这样的

1. **存进来**。每条已经结束的助手回复下面有两个图标动作，入口就是这两个：
   - **☆ 星标——「收藏到阅读板」**。只收藏，右侧栏保持原样，不会展开。收藏之后星标变成实心 ★，再点一次就是取消收藏：星标退回 ☆，聊天右侧「轮次导航」上这一轮的横线恢复普通样式，右栏同样不会打开。
   - **→ 箭头——「收藏并展开阅读板」**。收藏并展开右栏到「阅读板」标签页。已经收藏过的那条再点箭头，只负责展开，并提示这条回复已经在阅读板里了。
   - 也可以在主界面右上角的箭头图标点开阅读板，用面板底部的「+ 粘贴一段文字」把任意一段文字存进去。
2. **慢慢看**。右栏里显示的是**渲染之后的 Markdown**：标题、列表、引用、表格、代码块、粗体/斜体/行内代码/链接都按聊天区那样排版。卡片默认**整篇展开**，觉得太长可以点「收起」压成 120px 预览。
   - 卡片顶部右侧显示这条消息的时间：今天只显示 `HH:mm`，隔天显示 `MM-DD HH:mm`，跨年再补上年份。
   - 卡片左下角有「跳转」，点一下主对话会滚动到这条消息所在的位置；如果这一行还没被加载，它会沿着「加载更早」一页页往上翻直到找到，翻到会话开头仍没有才提示。
3. **选中即问**。在卡片里拖选一段文字，选择处会立刻浮出一个「→ 添加到主聊天」的胶囊按钮（和聊天区选中文字时浮出的引用按钮同一个位置和样式）；点它，这段文字以 Markdown 引用的形式进入主聊天输入框，你补上自己的问题发送即可。选中被清掉后按钮自动消失。
   - 想引用整条而不选文字时，用卡片左下角的「提问」。

## 它做什么、不做什么

- 内容保存在浏览器本地（按会话分开），刷新页面不会丢；清除站点数据会清掉。**收藏横线的外观是唯一的例外**：它不分会话，只存一份，对本机所有会话生效；改了之后，本机这个应用的其他窗口和会话也会立刻跟着变，不用刷新。
- 聊天右侧边缘「轮次导航」上那一排细横线里，被收藏的那一轮会变长（默认 26 像素）、变粗（4 像素）并换成亮色，每个收藏轮次各用一种亮色。这些横线只对已经加载在当前会话里的轮次生效；同一轮里收藏了多条回复，也只用那一轮的一根横线。
- 「设置 → 阅读板」就是调这些横线的地方，也只调这些：「统一颜色」开关（打开时多一个取色器）、「统一长度」开关（打开时多一个 22–28 像素的滑杆），外加一块效果预览。收藏横线最短的那档也比普通横线长。
- 更早的收藏没有轮次号。遇到这种记录，插件会去读会话历史（被动地、一页一页地读，拿到需要的就不再往下翻），据此认领它属于哪一轮，横线才上得了颜色；认领不到，就不画这根横线。
- 图标下面那行字只在鼠标停在图标上时出现；点完之后的反馈也一样，鼠标一移开就收走。
- 卡片上显示的是渲染结果，「复制」复制的是**原始 Markdown 源码**——想拿原文用它。
- 「提问」只做一件事：把引用的文字放进输入框。它不会替你发送，也不会自动补问题。
- 只有当前显示的会话才有可用的输入框；在别的会话的阅读板里点「提问」时，输入框不可用，插件会退化成「复制到剪贴板」并提示你。
- 引用长度有上限：来自回复的内容按 2000 字截断（那条回复本来就在会话记录里），手动粘贴的内容按 6000 字截断，超出部分以「…（后略）」标记。
- 每会话最多保留 40 条，超出后最旧的自动丢弃。
- Markdown 渲染是插件自带的轻量实现：标题、段落、列表（含一层嵌套）、引用、表格、围栏代码块、分隔线、粗体/斜体/删除线/行内代码/链接。**不渲染**数学公式、Mermaid、原始 HTML 与图片——这些会以文字形式出现。

## 入口

- 回复下方：每条结束的回复操作行里有两个图标——「收藏到阅读板」（☆，只收藏、不展开）和「收藏并展开阅读板」（→，收藏并展开右栏）；悬停才显示文字。
- 右侧栏标签页：「阅读板」（右侧栏的空状态指南页里也有它的入口卡片）。
- 会话标题右侧工具区：同一个箭头图标，直接展开右侧栏。
- 设置：「设置 → 阅读板」一节，调收藏横线的颜色、长度，并看效果预览。
